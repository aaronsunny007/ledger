# Ledger demo

Ask a question about a company's annual report (SEC 10-K). Every sentence cites the
filing and every number is re-checked by a calculator before you see it.

Free demo, so: a free CPU Space that sleeps when idle (the first load takes a few
minutes), a daily question quota shared by all visitors, and answers that are **not
investment advice**. Source and write-up: https://github.com/aaronsunny007/ledger

Owner setup (secrets, index, budget): `docs/deploy-demo.md` in the repository.
